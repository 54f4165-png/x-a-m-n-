# XOAIP USER V5 — GitHub Test

Đây là bản HTML xem trước để thử triển khai GitHub Pages hoặc Vercel (static site).

## GitHub Pages
1. Tạo repository mới trên GitHub.
2. Tải ZIP này về và giải nén.
3. Upload `index.html` và `README.md` vào thư mục gốc repository.
4. Vào Settings > Pages > Build and deployment > Deploy from a branch, chọn `main` và `/ (root)` rồi Save.

## Vercel
Import repository GitHub vào Vercel, chọn framework `Other` (static HTML), deploy.

## Lưu ý
- Đây là bản xem trước UI, không phải bản Firebase/ADMIN hoàn chỉnh.
- IP công khai ban đầu được truy vấn từ dịch vụ bên ngoài, cần mạng và có thể không khả dụng.
- Thay đổi IP/thiết bị chỉ thay đổi nội dung hiển thị trong web, không thay đổi IP hoặc thiết bị thật.
- Cấu hình lưu trong localStorage của trình duyệt hiện tại, không đồng bộ giữa các máy.
